Magnetisation-Unit-Conversion

A quick piece of code that converts between the two most common magnetisation units: emu/cm^3 and muB/atom.

Important: Lines 31 or 35 must be uncommented depending on which conversion is desired.

**Required parameters:**

NumberOfAtoms - Number of atoms in the unitcell

Volume - Volume of the unitcell

**Conversion from:**

MomentPerAtom - Magnetisation in units of Bohr magneton per atom

EmuPerVolume - Magnetisation in units of emu per cm^3
